# ops-skills

Public, sanitized operational skills for Codex.

This repository currently includes `jumpserver-server-login`, a Linux/macOS-oriented skill for validating Jumpserver prerequisites, logging in through Jumpserver with `ssh Jumpserver` and `totp jumpserver`, selecting a Linux asset, and executing an explicit command.

The repository must not contain real Jumpserver hostnames, internal asset addresses, key material, MFA seed values, OTP values, credentials, or personal absolute paths.
